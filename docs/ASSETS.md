## Elementi originali

Marchio ad anelli, favicon e campioni illustrativi CSS sono creati per questa demo; nessuna libreria di icone o marchio di terzi. Le frecce sono caratteri tipografici decorativi. I font utilizzano lo stack di sistema: nessun download, embedding o servizio font esterno. Le disponibilità dei caratteri dipendono dal dispositivo; Georgia è il fallback serif.
